# Data

The source corpus is **not** redistributed in this repository.

Download `TCM_SD_with_knowledge` from:

https://tianchi.aliyun.com/dataset/dataDetail?dataId=139034

and place the extracted files here. Expected layout:

```
data/
  TCM_SD_with_knowledge/
    train.json
    dev.json
    test.json
    norm_syndrome.json
```
